2. git checkout
    Give us an example how you checkout a git branch named "price limitation"
    Please provide your answer in the following editor
    answer: 
        # 中文回答：如何切换到名为"price limitation"的git分支
        
        # 1. 首先查看当前仓库状态
        git status
        
        # 2. 查看所有分支（包括远程分支）
        git branch -a
        
        # 3. 切换到"price limitation"分支
        git checkout "price limitation"
        
        # 如果分支不存在于本地，但存在于远程仓库，可以使用：
        git checkout -b "price limitation" origin/"price limitation"
        
        # 或者使用新的git switch命令（Git 2.23+）：
        git switch "price limitation"
